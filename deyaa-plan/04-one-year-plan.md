# 04 — خطة سنة (١٣ أكتوبر ٢٠٢٦ ← سبتمبر ٢٠٢٧)

> **مبدأ التصميم:** كل ربع فيه ٤ مجالات: **شغل · تعلم · علاقات · صحة**. وكل هدف ليه **مقياس رقمي** تقدر تقول عنه "اتحقق" أو "لأ" من غير جدال. المقاييس دي بتتسجّل في `tracker.csv` وبتتراجع في `07-review-system.md`.
>
> **ملحوظة عن الطموح:** الأهداف متصممة إنك تحقق **٧٠–٨٠٪** منها. لو حققت ١٠٠٪ يبقى كانت سهلة. ولو حققت أقل من ٥٠٪ يبقى الخطة محتاجة تتعدل، **مش إنت اللي فاشل**.

## الربع ١ — "الأساس والدليل" (١٣ أكتوبر ٢٠٢٦ ← ١١ يناير ٢٠٢٧) = خطة الـ ٩٠ يوم

| المجال | الهدف | المقياس |
|---|---|---|
| **شغل** | تفهم السوق من داتا حقيقية مش افتراضات | ٣٠ إعلان وظيفة متحللين في Sheet · **٥ محادثات** مع ناس شغالين Creative strategy/Performance |
| | أول Case study بـ Attribution أمين | Case study العقارات منشور (PDF أو صفحة) |
| | أول تحليل Creative analytics كامل | ≥ ٤٠ إعلان متعملهم Tag ومتحللين + صفحة Insights |
| | Dashboard | Looker Studio dashboard شغال |
| **تعلم** | الأساسيات (Sheets، مقاييس، إحصاء، A/B) | **≥ ٤٥ جلسة** (≥ ٢٥ دقيقة) من ٦٠ ممكنة · **≥ ٨ من ١١** نواتج أسبوعية اتسلّمت |
| | استرجاع | Anki: ≥ ١٥٠ كارت، و≥ ٨٠٪ أيام مراجعة |
| **علاقات** | قرب متكرر | ≥ **١٠ لقاءات** ١:١ (مع أصحاب/عيلة، ≥ ساعة) · Accountability partner متفق معاه |
| | المساعدة | ≥ ١٠ أفعال مساعدة (إجابة سؤال Junior، مراجعة شغل حد…) |
| **صحة** | نوم | ميعاد صحيان ثابت (±٦٠ دقيقة) في **≥ ٧٠٪** من الأيام · متوسط نوم ≥ ٧ ساعات |
| | العادة الليلية | عدد الليالي اللي ظهرت فيها العادة **بيقل** شهر عن شهر (المقياس اتجاه، مش صفر) |
| | حركة | ≥ ٣ مرات مشي/رياضة ٢٠ دقيقة في الأسبوع |

**بوابة آخر الربع:** مراجعة يوم ٩٠ (أكمل/أعدّل/أغيّر)، التفاصيل في `05`.
